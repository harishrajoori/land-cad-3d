# New Property Input Template

Use this when the property is not already recorded under `properties/`.

## Minimum one-line request

```text
Design for a [WIDTH] × [DEPTH] ft [SHAPE] plot in [LOCATION], with road(s) on [SIDES + WIDTHS] and house main door facing [DIRECTION].
```

Example:

```text
Design for a 40 × 60 ft rectangular plot in Karimnagar, with a 20 ft road on west and house main door facing north.
```

Unless explicitly overridden, use the family programme in `requirements/home-requirements.json` and all rules in `requirements/COMMON-DESIGN-RULES.md`.

## Input interpretation

| Input | Required to proceed? | Default / behavior if missing |
| --- | --- | --- |
| Plot width/depth or polygon | Yes | Ask for dimensions; do not guess |
| Which axis each dimension follows | Prefer | Infer from road frontage only when unambiguous; disclose inference |
| Road side(s) | Yes | Ask; road cannot be inferred from “facing” |
| Road width(s) | Prefer | Mark unknown; concept may proceed without parking-turn certification |
| Location | No | Default to Karimnagar, Telangana; disclose |
| Shape | No | Assume rectangular only when two dimensions are supplied; disclose |
| True/survey north | Prefer | Use north-up drawing convention, mark bearing unverified |
| Desired house-door facing | Prefer | Generate a reasoned candidate and mark consultant review |
| Family programme | No | Load current common requirements automatically |
| Legal setbacks/envelope | No for concept | Use clearly labelled provisional assumptions; never call legal |
| Site/road levels | No for concept | Mark unresolved; do not certify drainage/accessibility |

## Property record generated by Astra

When requested to save a property, create a Markdown file containing:

```text
Property ID and status
Location
North-up geometry / polygon
Arithmetic area
Road sides and widths
Desired gates and house-door facing
Owner property-specific preferences
Known survey/legal facts
Provisional assumptions
Unresolved inputs
Design implications
```

Do not store generated room layouts in the factual property file. Plans belong under `designs/<property>/` with revision IDs.

## Critical-question policy

Ask only when the missing fact prevents meaningful geometry:

- no plot dimensions/polygon;
- no road side/access information;
- contradictory dimensions/orientation;
- owner asks for final/legal/structural certification.

Otherwise proceed with disclosed provisional assumptions and deliver the best concept for review.
